# design-md

Manage the project's `DESIGN.md` as the authoritative source of truth for visual identity, design tokens, typography, and component patterns.

## Responsibilities
- Define and maintain design tokens in CSS custom properties (`--bg-primary`, `--accent`, etc.).
- Maintain contrast ratios compliant with WCAG AA (4.5:1 for body text, 3:1 for large text and UI components).
- Ensure UI components align with brand direction and prevent aesthetic drift.
