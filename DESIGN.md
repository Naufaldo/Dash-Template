# Industrial SCADA Design System Contract

## Color Palette (Tokens in `src/app.css`)
- **Surface**: `--bg-canvas` (#0c0e12 / #f4f6f9), `--bg-card` (#141820 / #ffffff)
- **Primary / Brand**: `--color-primary` (#00c853 / #00a844)
- **Warning**: `--status-warning` (#ffab00 / #e69500)
- **Critical / Trip**: `--status-critical` (#ff3d00 / #d50000)
- **Offline**: `--status-offline` (#607d8b / #78909c)

## Typography & Monospace
- System font stack for labels: Inter, -apple-system, BlinkMacSystemFont, Segoe UI.
- Tabular Monospace for values: JetBrains Mono, SF Mono, Consolas.
